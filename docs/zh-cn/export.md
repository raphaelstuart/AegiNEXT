# 视频导出

[English](../en/export.md) · [简体中文](export.md) · [全部指南](README.md)

## 导出视频

1. 打开**压制**面板，选择自动、H.264 或 HEVC。
2. 选择 CPU 或 GPU 编码、速度和画质模式。CPU 支持 CRF 或 Mbps；GPU 使用 Mbps。Mbps 模式下选择 VBR 或 CBR。
3. 选择复制源音频、AAC 或无音频；AAC 可设置音频码率。
4. 点击**导出**，选择尚不存在的 MP4 或 Matroska 文件。
5. 查看进度，必要时取消，完成后检查输出。

已保存工程的默认位置为 `项目目录/output/项目名-yyyyMMdd-HHmmss.mp4`，首次压制时自动创建 `output` 目录。保存对话框允许修改位置、文件名或选择 MKV；未保存工程须在对话框中选择输出位置。

参数校验、输出路径选择、任务启动或编码失败时会弹出错误原因，并将完整详情记录到日志。确认错误后可以修正参数重试；取消压制不显示错误弹窗。

导出在开始时捕获工程，通过独立 `aegn-exporter` 进程执行；后续编辑不影响任务。成功时原子提交新文件，失败/取消只清理自己的临时输出；已有目标文件会被拒绝。

## 选择 CPU 或 GPU

| 模式 | 参数与范围 |
|---|---|
| CPU，默认 | libx264/libx265；CRF 0–51（默认 20），或 VBR/CBR 0.1–200 Mbps；HDR 必须使用 |
| GPU | VBR/CBR 0.1–200 Mbps（默认 8 Mbps）；SDR H.264 8-bit 或 HEVC 10-bit |

CRF 数值越低，画质和体积通常越高。Mbps 为目标视频码率，按 1 kbps 精度向下规范化。VBR 允许码率随内容变化；CBR 采用恒定目标码率和受限缓冲，短片或单帧的实测码率不保证精确等于输入值。当前内部 VBR 峰值为目标的两倍，CBR 最低与最高均为目标，缓冲为峰值的两秒。

编码速度有 ultrafast 至 veryslow 共九档；软件编码使用对应 x264/x265 预设，硬件后端映射到支持的速度档位。

macOS 使用 VideoToolbox，Windows 尝试 NVENC/QSV/AMF 候选。当前 QSV 无法通过公开 FFmpeg 接口确认实际码控模式，会明确拒绝该候选。硬件、驱动、编码器或指定码控不可用时报告错误，不自动切换 CPU 或其他码控模式；关闭 GPU 可使用软件编码。GPU 加速视频编码，字幕合成仍采用线性高精度链路。

## 管理压制预设

在**设置 → 压制预设**新增或复制预设，编辑名称及编码参数后保存。选择已有预设并保存会修改该预设；**捕获当前配置**将当前工作台压制参数复制为新的独立草稿。切换选择、页面或关闭设置时，未保存的修改可以保存、恢复或取消切换。

列表支持多选；**导出**将选中的已保存预设写入一个 `.aegiexports` 文件。**导入**支持同时选择多个交换文件，每个文件也可包含多条预设。文件版本、参数、身份或名称冲突会拒绝整批导入，不部分入库。交换文件不包含工程、媒体路径、成片路径或工具路径。

回到**压制**面板，直接选择预设即可套用。个人库修改和导入只刷新可选列表，当前参数与未完成输入保持原样，直到主动选择预设；管理预设不会提交工程草稿或改变 Undo。

## HDR 与输入要求

编辑预览为 SDR；PQ/HLG 导出读取原始高精度帧并使用软件 HEVC 10-bit，HDR H.264 和 GPU HDR 会被拒绝。

- PQ 字幕参考白默认 203 nits；HLG 使用 1000 nits、零黑位参考条件。
- 保留完整静态 HDR10 mastering；合成后 MaxCLL/MaxFALL 设为未知 0/0。
- Dolby Vision/HDR10+ 等动态 HDR、变化/不完整 mastering 和不支持的色彩语义会被拒绝。
- 输入须为受支持的整数平面 YUV、方形像素，画布与可见视频尺寸一致；VFR 保留源呈现时间戳。
- 旋转、立体、ICC、交错、损坏/动态格式，以及封装链路不支持的负时间戳会报告错误。

复制音频保留包内容，AAC 使用选定码率。容器/时间戳不兼容时提供诊断，不静默移动源时间线。

ASS/SRT 文件见[字幕编辑](subtitle-editing.md)，应用包要求与校验见[发布](publishing.md)。
