# ASS 标签四维审查

[English](../en/ass-tag-audit.md) · [简体中文](ass-tag-audit.md) · [字幕编辑](subtitle-editing.md)

本审查以 2026-10-10 当前实现和 v11 原生模型为标杆，比较 Aegisub 官方 ASS 标签语义及实际导入、导出路径。AegiNext 的编辑模型可以超出 ASS；ASS 是交换边界，不是详情编辑器的数据源。不是“所有标签已完成”的兼容声明。

## 分类口径

- **超集**：该项原生能力包含 ASS 的可对应部分，并有额外能力；不意味着其全部组合能转换。
- **子集**：只覆盖部分参数、作用域、组合或播放语义。
- **未实现**：当前没有对应的原生表现；导入导出缺映射单独归入实现维度，不把它等同原生能力缺失。仅识别名称/报诊断不算原生实现。
- **已相同实现**：表中明确限定的参数语义一致；不指原始字节或所有播放器逐像素一致。

**无法转化 / 有损转换 / 无损转换**按两个方向分别列。无法转化表示当前路径不能搬运该项；文件其余正文仍可能导入。有损包括省略、近似、量化和不能保存的原生状态。表内的 **¹ 无损**仅限可对应参数：合法范围、所需字体/分辨率已知、数值落在输出精度网格、组合符合该行限定。超范围或其他组合按对应的有损/未实现行处理。

**导入 / 导出实现**分别使用 **无法完成 / 已完成 / 未完成**。已完成表示表述的当前转换或明确有损降级已实现；未完成表示缺映射或还未验证完整语义，理论可扩展不能据此标成无法完成。无法完成只用于表中明确限定、标准 ASS 一侧缺少表达能力的要求，不能靠保持标准 ASS 同时补齐。**剩余量**为少/中/高，指补齐该行剩余能力及验证的工作量；已完成且没有功能缺口的“少”表示仅有维护/回归成本，不是此前改动量或日历估算。格式本身无法表达的行即使标为“高”，也需要更换目标格式或设计附加原生数据，不能理解为增加代码即可使标准 ASS 无损。

## 容易误判的边界

空参数重置使用当时的重置样式；空颜色只恢复 RGB，空透明度恢复相应 alpha。整行几何和一般数值动画只有一套图层属性，行内不同几何不会自动变成局部变换。源标签被规范化为原生值，导出会选择显式值和标准别名；原文顺序、注释和冗余标签不往返。

空值重置只覆盖矩阵列出的样式/缩放/旋转标签；pos/move/clip/fad/fade/t 仍要求合法括号参数，k/kt 要求整数，结构非法可能拒绝导入。重复对齐、pos/move 和 fad/fade 采用首个值并诊断；后来的静态 clip/iclip 覆盖旧裁切，可能清除此前裁切动画并诊断。普通文字样式按后续文字范围保存，位置、换行、淡化及当前可映射几何按整行处理；不能由单标签通过推断任意混合/作用域都已相同实现。

多字演唱组在导入、打开、保存和日常编辑时保留身份与精确整组时间，范围外观与时间分离。首次启用无计时数据的句子会按字素生成；计时工具栏的“重置”显式重新生成整句，多选合并要求文字连续、时间相接且同模式。这些原生编辑命令不等于 ASS 转换暗中拆组。导出不为了写颜色而等分组。正空档可用空等待标签；重叠、倒序或负相对起点使用 kt 并提示外部工具限制。组起止独立量化，折叠的正时长至少 1 厘秒，可能新生重叠；范围超过 32 位毫秒播放器预算会拒绝。负起点导入以最早组重定内容原点，并同步原有 move/fade/t/蒙版时钟。

STEP/ko 的非零瞬时视觉转换包括负相对时间；零起点不写 t(0,0)，而写当前激活外观。ko 自身的未激活轮廓隐藏可以表达，额外的未激活颜色/阴影/描边状态不能据此认定全部可保存。SWEEP 的独立边缘与阴影、高亮范围和整行边缘动画的覆盖顺序仍有损。

阴影颜色 alpha=0 时，生成源差异不会造成可见阴影，不应报 ShadowComposition；描边颜色 alpha=0 仍不等于“无描边阴影”：外部 libass 仍用其轮廓生成阴影。实测零偏移、零 blur 的不透明阴影会使半透明字形在原生画面达到 alpha=1，而 libass 保持填充 alpha；带描边偏移阴影的墨迹扩张也超出几何对照阈值。对照测试明确分开计时/颜色指标、这些已报告的有损特征和透明阴影负对照；通过特征测试不代表渲染等价。详见 O。

SBS=“no”且缺少有效 LayoutRes 时，原视频尺寸未知，不能凭 PlayRes 宣称无损；当前采用目标画布像素并诊断。SBS 的数值归一化和输出 yes 不保原 header。矢量蒙版 n 的复杂组合是审计保留项：现有代码观察不能代替参考播放器对照，也不据此宣称已证实 bug。

## 数值、画面与字节

无损参数行不等于整文件无损：任一其他属性损失都会使该事件/文件成为有损转换。ASS 对白时间为厘秒，变换时间通常按毫秒，数值输出最多 9 位小数，颜色和 alpha 为 8 位，矢量蒙版输出 1/64 像素网格。原生任意有理时间、HDR/负颜色、独立模糊、缓存状态和资源不能全部装入标准 ASS。

不保证 Aegisub/libass/VSFilter 与原生逐像素一致：字体版本与塑形、排版前后缩放、非等比描边/模糊、阴影生成源/方向、整层透明度、组内样式段与蒙版采样都会改变结果。现有局部 libass 对照和单元测试不能推广为所有标签/组合的画面等价。字节无损也不提供：输出重新组织样式、标签与事件。
