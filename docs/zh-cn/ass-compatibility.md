# ASS 互转换能力

[English](../en/ass-compatibility.md) · [简体中文](ass-compatibility.md) · [全部指南](README.md)

本项目保留原生功能的完整表达能力。转换只发生在导入、导出层，无需兼容开关；有明确对应的部分转换，不能对应的部分给出损失提示。导出不改变工程。

逐标签的四维检查见 [ASS 标签审计](ass-tag-audit.md)：原生能力关系、两个转换方向、实现状态和剩余改动量分别列出。

## 判定方式

“对应”指两边有相同概念；“超集”指项目还支持 ASS 无法表示的取值或组合；“缺失”指原生编辑模型尚无对应功能。混合情况会列出具体缺口。

“已实现无损转换”仅指表中明确限定的参数和时间语义，不指文件逐字回写或跨渲染器像素相同。ASS 厘秒事件时间、整数毫秒变换时间、8 位 sRGB、字体选择与排版都会限制完整往返；项目保留的有理数时间、线性 HDR 颜色和自定义排版仍可能无法无损导出。转换提示是具体文件的判断依据。

## 能力矩阵

| 功能 | 原生功能相对 ASS | 转换状态与边界 |
|---|---|---|
| 文字、对白时间、叠层 | 超集 | 已实现无损转换：普通文字、厘秒边界及字幕前后关系。更细时间导出量化并提示；轨道身份不是 ASS 概念。 |
| 样式名、字体、字号、粗斜体、下划线、删除线 | 对应 | 已实现无损转换：ASS 可表达的样式属性；同名异样式和非法名称导出重命名并提示。字体资源与命名变体无法完整存入 ASS。 |
| 明确数值字重 | 部分对应、部分缺失 | 原生命名字体变体已保存 Weight；尚无任意 ASS 数值字重的直接编辑/转换。匹配字体变体时可实现无损参数转换但未实现，目前导入为普通/粗体并提示。 |
| 局部样式、`\r` 重置 | 对应 | 已实现无损转换：支持的局部字段；局部不同几何可保存为动画范围，轴心和布局仍有转换限制。 |
| 填充、描边、阴影颜色及各自 alpha | 超集 | 已实现无损转换：ASS 的 8 位 sRGB 子集；超范围线性颜色、HDR、额外精度无法无损输出。 |
| 描边宽度、阴影 X/Y 位移 | 对应 | 已实现无损转换：静态、可表示范围；非等比图层缩放与独立描边语义存在外观差异。 |
| 九宫格、三项边距、显式位置 | 超集 | 已实现无损转换：普通 ASS 对齐/边距/位置；独立文字对齐、自定义行高及任意原生轴心不能普遍无损表达。 |
| 整行缩放、Z 旋转 | 对应 | 已实现无损转换：受支持的静态参数。逐段变换导入为共享字幕锚点的文字范围；字形塑形、描边与阴影合成可能不同。 |
| 直线移动 `\move` | 超集 | 已实现无损转换：可表示的匀速直线区间；变速直线有近似提示，复杂路径无法无损转换。 |
| 淡入淡出 `\fad` / `\fade` | 超集 | 已实现无损转换：受支持包络的时间和不透明度参数；复杂原生包络不通用。整层合成后不透明度与 ASS 内部淡化的重叠像素不同。 |
| 字距 `Spacing` / `\fsp` | 对应 | 已实现无损转换：可表示精度的静态字距，包括局部覆盖、样式重置和常量动画；字距本身保留，跨引擎塑形可能不同。 |
| 填充模糊、描边模糊与 `\blur` | 超集 | 已实现边缘通道与模糊单位换算；无法普遍无损转换：ASS 根据描边是否存在选择模糊对象并耦合阴影，独立双模糊、独立阴影模糊及不同栅格算法不能同时保持。 |
| 换行 `WrapStyle` / `\q` | 部分对应、部分缺失 | 已实现无损转换：不自动换行与显式换行语义；自然换行对应 q1，但字体/断行算法不能保证完全一致。q0/q3 转自然换行并提示；平衡换行可实现但未实现；原生按字素导出 q1 并提示。 |
| 常用整行数值 `\t` | 超集 | 已实现无损转换：可表达的整行字距、描边宽度、边缘模糊、缩放和 Z 旋转参数及线性/幂函数/有序操作时序。局部不同动画、独立缩放轴保存为范围及有序分量操作；动态轴心和外观耦合有具体限制，复杂原生曲线导出采样并提示。 |
| 颜色动画 | 超集 | ASS RGB 与 alpha 独立保存分量及源顺序，使用 sRGB 插值元数据；原生线性颜色导出采样，8 位量化与 HDR 限制仍有损。 |
| `\k`、`\kf`/`\K`、`\ko`、`\kt` | 超集 | 已保留完整多字演唱组、独立起止、空档、重叠与倒序。ASS 可表达的厘秒时间与模式可无损转参数；必要的 `\kt` 有播放器兼容提示。独立前后描边/阴影、同组多样式运行、停用缓存及未计时状态外观有具体损失提示。 |
| 矩形、矢量裁切 | 超集 | 已实现无损转换：支持的静态几何、反相及可表达矩形变换；其他动画逐帧采样并报告舍入/采样。 |
| ASS `\p` 矢量文字绘图 | 部分对应、部分缺失 | 项目有独立贝塞尔形状，单轮廓几何可实现无损转换但未实现；文字/绘图混排和多轮廓语义尚未完整对应，不导入绘图命令为普通文字。 |
| ASS 不透明背景框 | 缺失 | 可实现对应效果但未实现完整背景框语义，目前提示省略。 |
| X/Y 伪三维旋转、剪切、`\be` | 缺失 | 暂未实现；低频功能不纳入当前优先补齐范围。 |
| 原生图片、形状、整层模糊、HDR 合成、效果脚本 | 超集 | 无法普遍无损转换；ASS 只输出可对应字幕，完整工程与视频导出保留这些能力。 |

## 本轮保真修复

- 导入多字演唱组后，打开、预览、文字编辑和保存不再自动按字等分。显式“拆分为逐字”或“重置”会重新分配；完全没有计时记录时，点击启用高亮也会首次按字素生成，已有记录则保留或恢复。完整 Unicode 字素和原始有理数边界得到保留。旧工程仅在 v3–v10 到 v11 的迁移阶段执行旧规则。
- 空 `\c` / `\1c`–`\4c` 重置 RGB，保留当前通道 alpha；空 alpha 重置其透明度。空 `\xshad`、`\yshad` 分别重置对应轴，空 `\an` / `\a` 使用当前重置样式的对齐。
- `ScaledBorderAndShadow: yes` 按目标/PlayRes 换算描边与阴影；`no` 使用目标/LayoutRes，缺失或不完整的 LayoutRes 使用比例 1 并提示。X/Y 阴影独立换算；非等比描边用几何平均近似并提示，不额外改变字体、位置、边距或 blur 的转换规则。
- 导出分别量化每组起止，保留窗外时钟和全部文字，不把后一组强推到前一组结束。普通累计标签足够时继续使用；重叠、倒序或事件之前的时钟使用 `\kt`。量化后消失的正时长保留至少一厘秒并提示；超出播放器 32 位毫秒范围时拒绝导出。
- 演唱、移动、淡化、数值变换和蒙版使用实际量化的事件起点。负等时外观变换保留；零起点不输出会被 libass 解释为整行渐变的 `\t(0,0,...)`，隐藏外观无法保存时明确提示。

原生阴影由填充字形生成，ASS 阴影包含描边；ASS 的零位移阴影也与原生叠加层不同。这些外观差异保留为有损转换诊断，不改变原生工程的渲染规则。原生未计时/停用文字的状态外观和停用计时缓存无法在普通 ASS 正文中保存，也会报告。

## 优先级

1. **P0：可靠转换与可核查损失**。已完成样式命名、时间/数值精度、独立阴影语义、逐条转换提示及取消安全性。
2. **P1：常用几何与透明度**。已完成静态变换、直线移动、淡入淡出，导入后使用原生编辑器。
3. **P1：字距、边缘模糊、换行**。原生模型、渲染、工程迁移、动画/脚本、三个 UI 入口及 ASS 静态转换已完成。
4. **P1：常用整行数值 `\t`**。已完成可对应数值动画的双向转换、原生轨道/UI 接入及具体损失诊断。
5. **P2：明确字重、平衡换行、矢量绘图**。需要独立设计与验证，不为兼容 ASS 降低当前模型。

字体附件、对话 Effect 字段、旧编码和 Aegisub 工程元数据不作为优先功能。

## 动画转换边界

- 导入单段连续变换为原生幂函数关键帧；重叠、瞬时或零加速度变换使用有序操作。支持与蒙版变换共存，内容时钟偏移不会重启动画；不同可见文字片段的基值与动画保存为独立范围，不再因全行差异丢弃。连续字号（含相对乘法）、阴影位移、各颜色与分通道 alpha 均进入原生轨道。
- 导出在线性、起始相位为零的幂函数及可表达有序操作上保持曲线；原生线性颜色和复杂曲线采样为 ASS 线性变换：输出分量误差目标为 1/255、最短间隔 1 毫秒、每轨道最多 4096 点；达到限制时明确提示可能超差。蒙版展开后的每条事件以实际 ASS 起点重定时，局部 `\r` 后重新写入动画。
- 缩放支持零值入场。原生镜像继续可编辑，但负缩放不强行写成 ASS 的普通缩放。非等比缩放、旋转阴影和独立模糊存在作用顺序差异；需要随时间改变位置的自定义轴心不能直接用固定 `\pos` 表达。
- 有序动画通过变换操作编辑器修改，普通数值框显示求值并提供提示；画布位置拖动仍可使用。普通缩放、旋转和描边宽度输入覆盖原生模型允许范围。

## 核查依据

ASS 标签含义参考 [Aegisub 官方标签文档](https://aegisub.org/docs/latest/ass_tags/)。自动化验证覆盖参数导入导出、时钟、原生求值、编辑撤销、持久化、渲染几何与 UI。[可选 libass 对照测试](../../Tests/AegiNext.Rendering.Tests/Reference/README.md)已在 libass 0.17.5 上运行，19 个用例通过：原有 1 个运行时与字体检查、7 个严格计时/颜色/透明度对照、5 个已知损失验证、3 个对照基准与反例，另加 1 个连续 RGB/alpha 中间值对照及 2 个绝对/相对字号墨迹增长对照。字号以各引擎 t0 墨迹尺寸归一，允许 3 像素偏差；Skia/FreeType 的基线字体度量不同，不能据此宣称字号像素无损。这些测试确认了所测行为及已报告的阴影差异，不代表所有标签组合都能跨渲染器像素无损。

文字动画范围及完整目标从 v12 起持久化。范围采用 UTF-16 完整字素边界，并跟随文字编辑、拆分、复制及工程合并重映射身份和引用。范围中心轴心、重叠几何、连续排版、独立状态边缘和跨零描边的 blur 路由均不能据此认定为跨渲染器等价。高级 ASS 投影展示可转换样式动画与范围几何；整层位置、缩放、旋转和不透明度由原生片段属性编辑。未改写的投影保留原生精度；明确改写文字仅在一个事务中替换文字目标轨道，保留整层动画。
