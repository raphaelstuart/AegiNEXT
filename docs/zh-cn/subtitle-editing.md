# 字幕编辑

## 时间线 Clip 定时

字幕 Clip 默认以 1 ms 增量移动、调整左右边界，裁剪后至少保留 1 ms 时长。启用 **Step** 时对齐当前标尺刻度；启用吸附时，Clip 的任一边缘可吸附其他 Clip 边界或当前播放红线，保留目标的精确时间。按住 Alt 临时绕过 Step 和吸附。

向左延长 Clip 会保留已有特效关键帧的工程时间位置；可在扩展后的整个 Clip 内移动或新增关键帧。每次拖动完成只提交一次，可通过 Undo 撤销。

选中 Clip 后，按 **Shift+Q** 定位到开始，按 **Shift+W** 定位到结束；多选时使用主选中 Clip。定位保持当前播放状态与缩放，并将视野外的目标带回时间轴可视区域。文本输入框保留大写 Q/W 的输入；可在**设置 → 快捷键 → 播放与试听**中修改或禁用。

在字幕列表或时间线中多选，右键选择**移动**，输入整数毫秒后点击**确定**。正值向后，负值向前；所有目标的起止时间按同一偏移调整，保留时长、相对间隔和内部动画时间。字幕列表移动已选字幕，时间线移动整个已选 clip 集合。取消或输入 0 不移动；任一目标越过零秒，或移动后字幕在同轨发生重叠，整批拒绝。一次 Undo 撤销整批移动。

## 富文本与卡拉 OK

选择字幕，通过视图菜单或字幕行打开**字幕详细编辑**。面板可停靠或浮动，富文本、高亮时间和高级代码三种视图编辑同一句字幕。

1. 选中文字，通过共享样式控件编辑局部字体、字号、强调、填充、描边或阴影。
2. 启用高亮后编辑按字素划分的卡拉 OK Clip；拖动边界调整时间，时长必须为正，前置空隙不能为负。
3. 打开**高亮样式**，编辑高亮填充、描边和阴影；选择预设立即应用。
4. **重置**丢弃尚未提交的内容、样式和时间草稿。

可选时长显示会显示全部 Clip 长度，默认仅拖动时显示。时长超过字幕范围时以红色溢出区域显示，不改变字幕边界。关闭高亮会保留 Clip，便于重新编辑。

有效草稿在 Enter 或失焦时提交，无效文字保持可编辑，Esc 恢复当前字段。文字修改保留未受影响的 Clip 身份和时间；完成一次样式/时间操作产生一条 Undo。

在**样式**面板通过两组图标按钮设置对齐：水平左／中／右、垂直上／中／下。切换一个方向时保留另一个方向，样式库也使用相同控件。组合值对应 ASS 的 `\an1`～`\an9`，在代码页修改该标签会同步样式面板；显式位置继续由位置编辑器控制。旧工程保留独立文字对齐，直到用户主动选择对齐，此时清除旧覆盖。

样式面板和设置 → 样式使用相同的四组与顺序：**字体、填充与描边、阴影、布局与位置**，各组始终展开。字体选择右侧同行放置粗体、斜体图标开关，下方字号与行高同行；填充和描边各占一行。布局与位置使用一张图同时展示边距和位置。设置页另保留预设命名、示例预览和样式库工具栏。

在定位行选择**自动排版**或**自定义锚点**。自动排版收起锚点、轴心和偏移输入，保留九宫格与图示；点击九宫格预设会进入自定义模式。切换模式保留图层的位置效果。样式面板的重置图标会恢复自动排版，并通过一次可撤销编辑清除位置偏移、运动路径和位置动画。设置页使用模式选择，不再提供重复的重置操作。

**边距**在样式面板和设置 → 样式中提供独立的**左、右、垂直**值，单位为画布像素。左、右边距限定自动换行区域，水平居中使用该区域的中心，因此不等边距会移动居中文字。垂直边距控制顶部／底部排版位置，垂直居中时忽略。显式位置接管定位并禁用垂直输入，左、右边距仍限定换行宽度。边距按文字排版计算，描边和阴影可以越过该范围；保留已有垂直基线位置。共用位置图展示排版区域和自动／显式位置。非法输入保留原文并阻止新预览、保存或应用；Esc 只恢复当前字段。

## 片段试听

顶部播放/暂停按钮试听选中 Clip，未选中时试听整句。**循环**重复播放范围，默认关闭；暂停时切换循环不会开始播放。

离开整个面板或浮窗失活会暂停。切换目标、关闭面板或在主窗口定位会取消旧范围；音频和视频同步播放。

## 导入与导出

| 菜单 | 格式 |
|---|---|
| 格式 → Aegisub → 导入 / 导出 | ASS 样式、卡拉 OK 和受支持的蒙版 |
| 格式 → SRT → 导入 / 导出 | 文字与时间 |

导入创建独立轨道，重叠字幕保留原时间并分配到额外轨道，一次 Undo 撤销整批。ASS PlayRes 映射到现有画布；结构、时间、尺寸、UTF-8 或资源限制无效时拒绝导入。

ASS 支持基础/局部样式、重置、颜色/透明度、描边/阴影、对齐/静态位置、`\k`、`\kf`/`\K`、`\ko`、矩形/矢量裁切及受支持的矩形变换。不支持的标签/动画需确认转换；`\move` 不导入为工程运动特效。

ASS 样式的 `MarginL`、`MarginR`、`MarginV` 分别映射三项边距。Dialogue 中非零值只覆盖对应项，零值继承样式。导入时左／右按 PlayRes 宽度比例缩放，垂直按高度比例缩放。导出分别写出三项，普通边距定位保持自动，显式 `\pos` 定位继续保留。导出使用 `WrapStyle: 1`；字体度量与换行仍可能与 ASS 播放器不同。

导出包含所有字幕轨道。SRT 报告富样式、高亮、蒙版和动画的损失；ASS 根据场景顺序生成层。工程保留精确时间，仅输出时量化为 SRT 毫秒或 ASS 厘秒。无法保留正卡拉 OK 时长时拒绝导出；文件使用 UTF-8 和原子写入。

## 合并多人分段工程

所有成员使用完整原片打轴时，在主工程选择**文件 → 合并其他工程…**，一次选择一个或多个 `.aeginext` 文件。

合并保留来源的原始时间，为每个来源新增“工程名／轨道名”独立轨道，保留轨道顺序和默认样式。字幕、富文本、卡拉 OK、形状、图片、图层组、动画、蒙版及工程内效果预设一并导入；来源图层按选择顺序追加到主工程合成树，保留各来源内部的绘制顺序。

主工程继续使用自己的视频、画布、帧率、参考白和时间轴视图。来源画布尺寸、参考白必须与主工程一致；帧率差异不改变精确字幕时间。此流程适用于时间已对齐的完整原片工程，不自动推断或移动分段时间。

字体和图片依赖复制到主工程的 `assets/`，相同内容复用资源；视频不复制。交付时应同时提供来源工程使用的托管字体、图片，系统字体仍需在汇总电脑安装。缺失资源、哈希不一致、损坏工程或超出预算会拒绝整批合并；备份先拷回来源工程根目录再导入。

一次 Undo 撤销本次选择的全部工程，Redo 可恢复；资源文件保留供历史使用。核对完成后保存主工程，重新打开仍可使用合并后的内容。

## 蒙版与高级代码

在**蒙版**面板创建矩形或闭合多轮廓贝塞尔几何，再在预览中编辑。蒙版使用工程坐标，仅裁切所属 Clip 的文字、描边、阴影、卡拉 OK 和自身模糊。字幕变换不移动蒙版，蒙版自身变换负责移动；支持反相和非零环绕规则的孔洞。

高级代码包含当前 Clip 蒙版。兼容修改保留节点身份和动画；节点形变存在时，须先清除节点轨道再修改拓扑。文字、蒙版及动画一并提交。

ASS 将可精确表达的矩形动画输出为 `\t`，其他蒙版动画展开为逐帧静态事件并报告采样与坐标舍入。展开的卡拉 OK 使用绝对 `\kt` 时间，目标播放器须支持它。导出上限为 100,000 条事件。
