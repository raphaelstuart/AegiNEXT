# Four-dimensional ASS tag audit

[English](ass-tag-audit.md) · [简体中文](../zh-cn/ass-tag-audit.md) · [Subtitle editing](subtitle-editing.md)

This assessment uses the current implementation and v12 native model on 2026-10-10 as the baseline, comparing Aegisub's official ASS tag semantics with actual import/export paths. The native editor can exceed ASS; ASS is an interchange boundary rather than the details editor's source model. This is not a claim that every tag is implemented.

## Classification

- **Superset (超集)**: native capabilities include the representable ASS part and additional behavior; not every combination necessarily converts.
- **Subset (子集)**: only some parameters, scopes, combinations, or playback semantics are covered.
- **Unimplemented (未实现)**: no corresponding native behavior exists. Missing import/export mappings belong to the implementation dimension rather than the native-capability dimension; recognizing a name or reporting a diagnostic is not native implementation.
- **Equivalent (已相同实现)**: the expressly bounded parameter semantics match, without byte or universal pixel equivalence.

**Unavailable / Lossy / Lossless** are assessed in each direction. Unavailable means the current path cannot transfer that feature, although the rest of the text may import. Loss includes omission, approximation, quantization, and unrepresentable native state. **¹ Lossless** refers only to representable parameters: valid ranges, known required fonts/resolutions, values on the output precision grid, and the combinations specified in that row. Other ranges/combinations follow their lossy or unimplemented rows.

**Import / export implementation** uses **Impossible (无法完成) / Complete (已完成) / Pending (未完成)**. Complete means the stated conversion or explicit lossy fallback exists; Pending means missing mapping or unverified full semantics. A theoretically extensible feature is not Impossible. Impossible is reserved for a stated requirement that the standard ASS side of the interchange cannot represent. **Remaining effort**, Low/Medium/High, measures work to close the remaining capability/verification gap. Low on completed rows means maintenance/regression only, not past change size or a calendar estimate. A High estimate on a format-impossible row requires another target format or additional native data; more converter code cannot make unchanged standard ASS lossless.

## Boundaries that are easy to misclassify

Omitted-parameter resets use the current reset style. Empty colors reset RGB only; empty alpha resets the corresponding alpha. Whole-line and visible ranges retain independent styles and 2D geometry. UTF-16 ranges use full grapheme boundaries; overlapping styles follow range order, while stacked geometry has explicit export limits. Project v12 persists range identity, state, color space and component operations. Tags normalize into native values and export as explicit values/canonical aliases, losing original order, comments, and redundant tags.

Omitted-parameter resets cover only the style/scale/rotation tags listed in the matrix. pos/move/clip/fad/fade/t still require valid parenthesized arguments and k/kt require integers; malformed structures can reject import. Duplicate alignment, pos/move, and fad/fade use the first value with diagnostics. Later static clip/iclip overrides the previous mask and can clear previous mask animation with a diagnostic. Ordinary text styles apply to following text ranges; placement, wrapping, fades, and supported geometry use whole-line state. Single-tag support does not prove arbitrary mixtures or scopes equivalent.

Import, open, save, and everyday edits retain multi-character group identity and exact whole-group timing independently of range appearances. First enable with no timing data generates grapheme timing; the timing toolbar's Reset explicitly regenerates the line. Multi-selection merge requires contiguous text, touching times, and matching modes. These native editing commands do not imply implicit splitting during ASS conversion; export does not divide a group to write colors. Empty waiting tags handle positive gaps, while kt handles overlapping, backward, or negative relative starts with a tool-compatibility warning. Start/end quantize independently, retaining at least one centisecond for a collapsed positive duration and possibly creating overlap. Values outside the 32-bit millisecond player budget reject conversion. Negative import starts rebase the content origin from the earliest group, shifting existing move/fade/t/mask clocks consistently.

Nonzero instantaneous STEP/ko visual transitions include negative relative times. Zero-start groups write the active appearance rather than t(0,0). Built-in inactive ko outline suppression is representable; additional hidden color/shadow/outline states are not automatically preserved. Independent SWEEP edges/shadows and precedence conflicts between range styles and whole-line edge animation remain lossy.

A shadow color with alpha=0 makes the shadow-source difference invisible and must not trigger ShadowComposition. Outline color alpha=0 does not remove the contour from libass shadow generation. In measured zero-offset, zero-blur cases, an opaque native shadow raises partially transparent glyphs to alpha=1 while libass retains fill alpha; outlined offset shadows also exceed the geometry-comparison tolerance. Reference tests separate timing/color metrics, reported lossy characterization, and transparent-shadow negative controls. Passing a characterization test does not establish render equivalence; see O.

With SBS=no and no valid LayoutRes, original video dimensions are unknown; PlayRes alone cannot establish losslessness. The current fallback uses target-canvas pixels with a diagnostic. Numeric normalization and output yes do not retain the original header. Complex vector-mask n combinations remain an audit reservation: code inspection cannot replace reference-renderer comparison or establish a bug.

## Parameters, frames, and bytes

A lossless parameter row does not make an entire file lossless: loss in any other property makes its event/file lossy. ASS dialogue times use centiseconds; transforms generally use milliseconds. Numeric output retains at most 9 fractional digits, color/alpha use 8 bits, and vector masks use a 1/64-pixel grid. Standard ASS cannot hold all arbitrary native rational times, HDR/negative colors, independent blur, cached state, and resources.

Pixel identity between the native renderer and Aegisub/libass/VSFilter is not guaranteed. Font versions/shaping, pre-/post-layout scaling, anisotropic outline/blur, shadow generation/direction, post-layer alpha, style runs, and mask sampling can differ. Isolated libass comparisons and unit tests do not establish universal equivalence. Byte identity is also unsupported: export reorganizes styles, tags, and events.
