# 交互预览 CPU 管线性能验收

[English](../interactive-preview-performance.md) | [简体中文](interactive-preview-performance.md)

日期：2026-10-05；本机 macOS / ARM64。每组 32 次目标，首个冷启动样本单独保留、分位数基于其余 31 次。所有原始样本及视频 PTS 在 `artifacts/verification/interaction-performance.json`。

使用真实视频解码、SDR 转换、3840×2160 工程及四条自然文字动画字幕。基线为本轮修改前保留的 `AegiNextWorkspacePreview.app` 渲染程序集；同一测试驱动分别引用旧程序集和当前源码。数据包含 CPU 解码、转换、场景合成，不包含 UI 上传、屏幕刷新或输入延迟。

| --- | ---: | ---: | ---: | ---: | ---: |

4K 压力媒体由同一真实视频转码：3840×2160、8 秒、仅 1 个 I 帧、非均匀帧间隔；目标在 4–7 秒间交替跳转。原始 FFmpeg 转码日志和逐帧样本保留在验证目录。

该压力场景的重新解码仍是主要成本，不能声称最新视频背景能达到每帧实时。交互调度复用最近背景，在后台对最新求值时间合成字幕/特效；一个执行请求和一个可覆盖的等待目标防止排队，此测量阶段松手恢复 1280×720。后续画质选择默认 960×540，松手恢复用户所选级别；本表未按新画质选项重新测量，不代表所有级别性能。CPU 合成降低与真实触控板/屏幕流畅度验收分别记录。

取消发生在安全阶段边界，取消后缓存必须重新完整生成；旧序号、场景 revision、求值时刻及端点编辑层身份不能替换最新画面。相关调度、像素与取消恢复定向测试已执行。
