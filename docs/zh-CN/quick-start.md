# Quick Start · 用户快速开始

[English](../quick-start.md) | [简体中文](quick-start.md)

本手册面向 AegiNext **0.1.0 开发预览**，带你完成打开视频、制作字幕、保存工程和压制成片。界面可在中文和英文之间切换，以下以中文菜单为例。

## 1. 启动应用

使用与你的平台对应的完整开发发布包，解压后打开：

- macOS：`AegiNext.app`。当前本机生成的 Apple Silicon 开发包要求 macOS **27.0 或更新版本**；具体包的最低版本见其 `package-manifest.json`。
- Windows：发布目录中的 `AegiNext/aegi-next.exe`。当前开发发布包为 **x64**，已在 Parallels 的 Windows 11 ARM64 环境通过 x64 模拟运行验证。

完整发布包包含 .NET 运行时、FFmpeg／FFprobe、音频和压制依赖，使用时保留整个应用目录。自行从源码运行请看 [构建说明](building.md)。

主工作区包含预览、时间线、字幕、样式、特效、压制和日志七个面板。第一次使用可以通过“布局 → 标准”恢复常用排布；隐藏的面板可从“视图”菜单重新打开。

## 2. 打开视频与保存工程

1. 通过“文件 → 新建工程”开始一个新工程。
2. 通过“文件 → 打开视频”选择素材，等待预览载入。时间线的音频分析会在后台生成。
3. 通过“文件 → 另存为”保存为 `.aeginext` 工程，后续使用“保存”记录修改。

工程保存字幕、轨道、样式与动画数据。视频保持为原文件引用；重新打开工程时仍需要该视频位于可访问的位置。工程保存与导出成片是两个独立操作。

当前工程格式为 v3，打开 v1／v2 工程会提示不支持。

标题显示为 `AegiNEXT - 工程名`，存在未保存修改时末尾显示 `•`。已保存工程使用工程文件名；未保存且未命名的工程使用视频文件名。另存为成功后更新名称，取消或失败保留当前名称。

预览画质可选低（540p，960×540）、标准（720p）、高（1080p），默认低画质；小视频不会放大。画质属于个人设置，重启恢复。拖动时最高 540p 且不超过所选画质，松手恢复所选画质；不会改变压制分辨率或 HDR 链路。

视频预览只保留面板标题，画面右上角固定显示 SDR／HDR 状态徽标；当前编辑预览输出 SDR。画面下方的正方形按钮控制播放／暂停，中间显示居中的时间，右侧为静音按钮和音量条。

## 3. 选择轨道，制作第一条字幕

先点击时间线左侧的轨道标题或轨道空白区域，选中字幕要加入的轨道。新增和快捷键打轴都使用当前选中的轨道；点击已有 Clip 会同步选中其所属轨道。

轨道的创建、改名、排序、折叠和删除空轨道位于时间线右键菜单。字幕面板顶部的轨道下拉框可以切换列表所显示的轨道。

先在“设置 → 字幕样式”中保存预设，再右键目标轨道选择样式。轨道标题下的徽标显示已保存的样式名称。更换非空轨道的预设时，会询问是否修改已有 Clip：选“是”更新已有字幕及后续默认值；选“否”保留已有字幕，只更新后续默认值；选“取消”不修改。默认选“否”，没有全部轨道批量应用入口。可以关闭轨道自动应用；此时保留轨道预设，但新增字幕使用样式面板当前选中的预设。重新开启后，后续创建再使用轨道默认值。样式和字体资源在一次事务中提交，字幕时间与特效保持原值，可撤销。拆分和跨轨移动保留 Clip 自身样式；个人预设库后续修改或删除不会自动改写工程快照。

### 手动添加

1. 将播放头定位到字幕开始的位置。
2. 在字幕面板顶部点击“新增”，或按 `Cmd/Ctrl + Enter`。新增字幕默认长度为两秒。
3. 在字幕列表输入文字，设置开始和结束时间。时间字段可输入秒数，也可输入 `00:00:12.350` 这样的时分秒格式。
4. 在时间线上拖动 Clip 主体移动整句，拖动左右边缘调整长度。

同一轨道的字幕不能重叠。遇到碰撞时修改会被拒绝；可以调整时间或把 Clip 放到其他轨道。

### 使用播放打轴

1. 选中目标轨道，在非文本输入区域按空格开始播放。
2. 听到一句开始时按 `F8`，创建新的字幕并记录起点。
3. 听到这一句结束时按 `F9`，完成当前打轴段。
4. 在字幕列表填写文字，复查时间和画面。

`F8` 始终创建新句。`F9` 只结束仍然有效的本次打轴段；开始和结束之间如果执行了编辑、选择、寻址或切出窗口等操作，该段会失效，可以重新开始打轴。系统占用了功能键时，也可以使用“字幕”菜单，或在设置中修改绑定。

已有字幕可以从“文件 → 导入字幕”导入 UTF-8 SRT／TXT。导入使用当前轨道，同轨重叠会整体拒绝并显示冲突。

## 4. 调整样式与位置

选中字幕后打开“样式”面板，设置字体、字号、颜色、描边、对齐等属性。字幕随文字内容自然伸展，字号独立设置。

需要指定位置时启用显式位置，使用九宫格锚点、Pivot 和像素偏移：

- 普通点击锚点预设保持文字当前实际位置。
- 按住 Shift 点击，同时设置 Pivot。
- 按住 Alt 点击，同时把位置偏移归零。

视频预览可以直接拖动字幕位置。在样式位置编辑器或特效面板点击“恢复自动位置”，即可回到当前样式的自动对齐。这个操作同时清除自定义锚点位置、手动位移、位置关键帧、运动路径及路径进度动画；保留字号、缩放、旋转和透明度等其他效果，可以一次撤销恢复。

锚点、轴心和偏移各使用一行 X/Y 向量输入。锚点和轴心取值 0–1，偏移以像素为单位；Esc 仅恢复当前输入的分量。自动水平对齐按实际字形边界计算，居中字幕恢复后的水平偏移为 0；左／右对齐继续使用样式边距。

颜色字段是一条连续输入栏，从左到右为正方形颜色预览、输入区域、正方形模式按钮和正方形取色按钮。点击模式按钮在 HEX 与 RGBA 之间切换：HEX 接受 `#RRGGBB` 和 `#RRGGBBAA`，透明度在最后，六位表示不透明色；RGBA 使用四个 0–255 整数，例如 `255,255,255,255`。点击右侧取色按钮展开取色框，选择后同步输入与颜色预览。Enter 或失焦提交有效输入，非法输入保留并提示，Esc 恢复当前颜色字段。两种输入均表示 sRGB；仅切换模式、语言或刷新界面不会量化未编辑的 HDR 工程值。

填充与描边各是一条完整颜色动画，时间线同一属性行显示 RGB 曲线和独立的 Alpha 区域。样式面板的“恢复自动位置”位于对齐选择旁边。预设区通过统一“应用预设”使用内置及个人脚本，设置脚本页只管理模板。

位置、缩放和对应动画都是完整二维向量。特效面板以一组 X/Y 编辑一个变量，改变一个分量时会保留另一个分量，时间线也将两个分量显示在同一属性行。曲线的淡蓝色为 X、橙黄色为 Y；横向拖动改变该关键帧共有时间，纵向拖动只改变命中的分量。X/Y 重叠时显示一个黄色填充、白色边框标记，纵向拖动同时增加或减少两分量。数值只在悬停关键帧时显示。

可复用的字幕样式在设置的“字幕样式”页管理，支持导入／导出 `.aegistyles`，包含样式、位置和已导入的字体资源。系统字体仍需要目标机器安装相应字体。

需要逐字变色时，在样式面板的“高亮样式”中选择预设，再点击“逐字高亮”。高亮使用预设的填充、描边、描边宽度和阴影，保留原字幕的字体、字号与排版。已有逐字高亮时，重新应用只替换外观，保留逐字时间；选择“默认高亮”使用原有默认颜色。“清除高亮”同时移除逐字片段和高亮样式快照。工程保存独立快照，不依赖个人预设库中的条目继续存在。

## 5. 添加特效与编辑关键帧

1. 在时间线上选中字幕 Clip，打开“特效”面板。
2. 使用“淡入淡出”、单独“淡入／淡出”、“弹入／弹出”或“滑入／滑出”应用效果。
3. 点击轨道头的 ◆／◇，展开 Clip 所在轨道的动画区。该轨道所有 Clip 的已有动画属性持续显示，各自曲线位于对应 Clip 的时间范围内。
4. 点击一个关键帧，视频会暂停并定位到该时刻。可以拖动关键帧修改时间和值，也可以在特效面板修改数值和插值方式。

特效面板直接编辑时间线选中的字幕，开始、结束时间输入上方有对应提示；字幕内容在字幕面板修改。

关键帧时间限制在所属 Clip 内。选中关键帧后修改其他动画属性，也会使用同一个目标时间。非法数值会保留并显示错误；按 Esc 恢复当前字段，再继续切换编辑目标；播放、寻址和视窗导航仍可操作。

视频预览是画面编辑入口，位置控制柄与特效属性联动。效果也可以通过撤销／重做恢复。

在“设置 → 特效脚本”中管理高级 [DSL 模板](effect-dsl.md)。选中内置脚本后“另存为”个人模板，再编辑固定段、自由段和关键帧；内置源保持只读。编辑器提供语法高亮，输入时自动在光标附近显示上下文补全，也可按 `Ctrl/Cmd + Space` 打开；使用方向键选择、Enter/Tab 插入、Esc 关闭。补全不抢输入焦点，输入法预编辑期间收起。点击“验证”检查源代码，错误会给出行列；“定位错误”将光标移到该处。

个人模板可以改名、保存、删除、导入和导出 UTF-8 `.aegifx`。应用时按当前 Clip 时长重新编译：固定入场／出场优先，自由段占剩余时间，短片段根据脚本中的 `compress` 或 `reject` 处理。模板保存于个人设置，切换工程继续可用；只有明确保存才更新模板。未保存源在设置窗口内切换模板和语言后仍保留。

编辑运动路径时，在特效面板点击“添加路径点”，或在视频预览的路径编辑模式中双击空白画布追加端点；拖动端点与白色控制柄调整曲线。“删除末端路径点”保留至少两个端点，“清除路径”也清除路径进度动画。图形、图片、分组和蒙版没有工作台编辑入口。

时间线左侧竖条提供磁铁图标的“粘滞”和“步进”：粘滞将移动／裁剪／关键帧吸附到其他 Clip 的开始或结束，吸附成功时在目标时间显示竖向框线；步进按当前视窗最小刻度对齐。Alt 可临时绕过，吸附框线随之收起。粘滞默认开启，步进默认关闭；未开启步进时仍以项目帧精度拖动，Alt 使用毫秒精度。放大后刻度细化至毫秒。

同一竖条有两个独立的音频显示按钮，分别开关能量图和波形。隐藏仅改变显示；重新打开不需要重新分析，停靠或浮动面板时保留当前开关状态。

## 6. 保存字幕并压制成片

制作过程中使用 `Cmd/Ctrl + S` 保存工程。如果只需要字幕文本，通过“文件 → 导出字幕”输出 SRT；它会导出全部字幕轨道。

压制成片时：

1. 打开“压制”面板，默认使用 CPU 软件编码，可调整速度和 CRF 质量。
2. 根据需要选择自动、H.264 或 HEVC，以及原音轨复制、AAC 或无音频。勾选“使用 GPU 硬件视频编码”时使用硬件视频编码，改为设置视频码率；字幕合成仍使用现有高精度链路。硬件编码不可用时显示具体错误，可取消勾选后使用 CPU。HDR 素材使用 CPU 编码。
3. 点击“压制”，选择一个尚不存在的输出文件，例如 `完成字幕.mp4`。
4. 查看进度，完成后打开成片检查字幕、画面和声音。需要中止时点击“取消”。

压制使用启动时的工程快照，后续编辑不会改变正在运行的任务。程序要求输出为新文件；取消或失败会清理本次临时输出。

编辑预览显示 SDR；PQ／HLG 素材的压制使用独立的高精度链路。HDR 输出使用 HEVC 10-bit，支持条件和拒绝规则见 [压制说明](export.md)。

## 常用快捷键

macOS 使用 Cmd，Windows 使用 Ctrl。下表是默认绑定，修改后的实际绑定可以在菜单和设置中查看。

| 操作 | 默认快捷键 |
|---|---|
| 新建工程 | Cmd/Ctrl + N |
| 打开工程 | Cmd/Ctrl + O |
| 打开视频 | Cmd/Ctrl + Shift + O |
| 保存／另存为 | Cmd/Ctrl + S／Cmd/Ctrl + Shift + S |
| 播放／暂停 | 空格 |
| 打轴开始／结束 | F8／F9 |
| 新增字幕 | Cmd/Ctrl + Enter |
| 撤销／重做 | Cmd/Ctrl + Z／Cmd/Ctrl + Shift + Z |
| 导入字幕 | Cmd/Ctrl + I |
| 导出 SRT | Cmd/Ctrl + Shift + E |
| 压制视频 | Cmd/Ctrl + E |
| 打开设置 | Cmd/Ctrl + , |

文本框中的空格用于输入文本，展开的菜单／下拉框和模态窗口保留各自的键盘操作。未展开的顶部菜单项仅获得焦点时，仍可使用 F8 打轴和空格播放等全局快捷键。

修改绑定时，在“设置 → 快捷键”选中命令，点击“录入”后直接按组合键，释放全部按键，再点击“保存快捷键”。手势框只显示录入结果，不接受输入或粘贴文字。冲突提示会指出占用该手势的命令；录入当前命令已有的手势可正常保存。按 Esc 取消录入，“清除”禁用当前命令的快捷键。

## 时间线导航、布局与设置

- 普通滚轮上下滚动轨道；Shift＋滚轮水平移动；Ctrl／Cmd＋滚轮以指针位置为中心缩放。触控板支持捏合缩放和横向滚动。
- 顶部 Minimap 显示工程概览与当前视窗。拖动视窗平移、拖动边缘缩放；这些操作不会改变视频播放位置。
- 可以拖动面板标题重新停靠、合并标签或浮动。通过“布局”切换内置预设，或另存为个人布局。当前布局会自动记忆，命名预设通过明确保存更新。多标签的当前项使用高亮文字及底色，不绘制标签框线。
- 从菜单进入设置，调整主题、语言、快捷键和字幕样式。macOS 可在外观设置切换系统菜单或主窗口菜单。
- “设置 → 配色”集中调整高亮色和音频图配色。音频图提供经典、冰蓝、暖焰、灰阶方案，可直接往返切换；也可单独编辑低／中／高能量颜色和波形颜色。内置方案随深浅主题自动适配，经典在深色主题保留原来的语谱映射；手动修改或选择自定义后，颜色按输入原样显示。有效颜色立即应用，设置页的小图可预览实际主题下的配色；波形支持透明度。“恢复默认配色”同时恢复高亮色和经典音频图，清除颜色草稿并立即保存，保留主题、语言、快捷键等其他设置。
- 工程修改需要手动保存；布局和外观设置的自动记忆不会替代工程保存。

## 遇到问题

通过“视图 → 日志”查看错误详情。有完整异常的记录可直接展开，阅读并选择文字；日志支持过滤、复制和清空，关闭应用前可以复制需要报告的内容。

| 现象 | 处理方式 |
|---|---|
| 面板消失或布局混乱 | 从“视图”重新打开面板，或切换“布局 → 标准” |
| 无法切换字幕或关键帧 | 检查输入字段的错误，修正或按 Esc 恢复当前字段 |
| 新增、拖动或导入被拒绝 | 检查同一轨道是否有时间重叠 |
| 打开工程时找不到视频 | 将原视频恢复到工程记录的位置；移动工程时同时保留视频及托管资源 |
| 提示 DLL 或 native 依赖缺失 | 重新解压完整的平台包；保留应用、worker、工具和运行库目录，并复制日志中的完整错误 |
| 压制不能开始 | 检查字段错误、媒体诊断和输出路径；输出文件必须尚不存在 |

进一步操作见 [工作台手册](workbench.md)；开发与排错文档见 [文档索引](README.md)。
