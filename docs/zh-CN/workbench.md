# 字幕工作台

[English](../workbench.md) | [简体中文](workbench.md)

工作台采用预览、时间线、字幕、样式、特效、压制、日志七个固定面板和可组合停靠空间：可拖拽重排、分割、合并标签、隐藏及浮动；顶部“布局”菜单可切换标准、打轴、特效、压制或个人预设，当前布局自动记忆。项目名称和未保存标记合入标题栏，设置通过菜单进入。此前停靠实现见 [可组合工作区](composable-workspace.md)，当前标题、配色和编码选项见 [本轮验收](checkpoints/export-title-colors.md)。

主窗口标题顺序为 `AegiNEXT - 项目名 •`，仅未保存修改时显示末尾圆点。已保存项目显示项目文件名；未保存项目优先使用显式项目名称，默认未命名时显示视频文件名，没有媒体时显示本地化的未命名项目。另存为成功后刷新标题和下次保存建议名，失败或取消不改变名称。系统标题与自建标题栏同步；浮窗附加当前面板名称。这是显示投影，不改项目数据或 Undo。

首版采用 .NET 10 / Avalonia，自有项目扩展名为 `.aeginext`。工作台围绕一个视频、字幕与特效场景组织；支持导入 UTF-8 SRT／TXT 和导出 SRT，ASS 适配留待后续版本。

## 基本操作

预览画质支持低清（320p，568×320）、流畅（540p，960×540）、标准（720p）、高清（1080p），默认流畅；不放大小视频。选择属于个人偏好，重启后恢复。交互预览最高 540p 且不超过所选画质，选择 320p 时拖动仍保持 320p，松手恢复所选级别，不改变项目或压制分辨率。

视频预览底部使用紧凑控制栏：左侧 32×32 播放／暂停图标按钮，中间时间文字水平与垂直居中，右侧 32×32 静音／取消静音按钮及音量条。静音保留原音量；悬停按钮显示当前操作提示。进度条与控制栏保持小间距，专用 Slider 主题缩小模板内部留白，保留完整的 20×20 Thumb 与居中轨道。

清晰度选择器与 SDR／HDR 徽标共用一行 32 DIP 高的画面叠层。拖动时间线播放头或预览进度条时，鼠标按住期间持续请求视频帧，返回拖动起点也会更新画面。松手精确定位并恢复所选预览画质；拖动使用暂停状态预览，不启动正常播放。

轨道标题中的单个三角用于展开／收起全部已有动画属性行，没有独立的菱形展开按钮。收起后字幕 Clip 仍然可见，动画数据保留。轨道名称与样式徽标使用统一中英混排字体链和居中的行框。

面板内不重复显示“视频预览”标题；文件名称保留在画面提示中，模式徽标固定在画面右上角，不拦截画布输入。当前合成预览显示 SDR，模式文字不按源视频标签误报 HDR。Dock 标题、内容和浮动面板使用统一圆角及主题描边；布局层独占外框，业务面板不重复绘制。标签条不画补位分隔线或标签边框，活动标签仅通过主色文字及半透明底色标识。

1. 从“文件”菜单新建／打开项目、打开视频、保存、导入导出。菜单按文件、编辑、视图、播放、字幕组织，菜单项与按钮共享命令及可用状态；macOS 使用系统菜单，未导出原生菜单的平台在窗口顶部显示菜单。
2. 点击时间线轨道标题或空白区域只选中轨道，新增、打轴和导入落入该轨道；轨道创建、重命名、排序、折叠和删除空轨道统一在时间线右键菜单。字幕面板顶部的轨道选择与新增、删除、拆分、合并处于同一操作栏，字幕列表按当前轨道筛选；点击 Clip 同步轨道选择。轨道只组织字幕，不改变图层合成顺序。同轨 Clip 不能重叠，跨轨放置和导入遇到冲突时原子拒绝，不自动调整时间。
3. 默认空格播放／暂停；F8 始终新建一句，不修改选中的已有字幕；F9 只结束本次仍有效的 F8 打轴段。重复 F8 不重复新建；未进入时 F9 不修改项目。进入后若点击、滚动、编辑、跳转、执行其他命令或切出窗口，本次退出立即失效，再次 F8 新建下一句。碰撞拒绝保留项目和打轴状态。时间字段接受秒数或 `hh:mm:ss.fff`，失去焦点提交，非法输入显示错误并保留草稿。
4. 在时间线上拖动字幕主体移动整句，拖动边缘裁剪；按住 Ctrl 拖动边缘执行时间拉伸。默认以项目帧精度拖动，并开启粘滞对齐其他 Clip 边界；开启步进后按当前视窗最小刻度量化。Alt 临时绕过粘滞与步进，使用毫秒精度。拖动结束形成一条撤销记录。顶部 Minimap 显示当前视窗和播放头，拖动视窗平移、拖动边缘缩放、点击定位视窗，这些操作不寻址视频。普通滚轮垂直滚动，Shift＋滚轮水平移动，Ctrl／Cmd＋滚轮及触控板捏合以指针为中心缩放；触控板横向滚动平移时间轴。
5. 在样式页通过可搜索下拉框选择系统字体或项目已有字体，修改字号、颜色、描边、粗斜体和对齐。字幕按文字自然伸展，字号独立设置。启用显式位置后可设置 Anchor、Pivot 与像素偏移；三者各使用同一行 X/Y 向量输入。Pivot 以实际文字字形边界计算，Anchor 为画布归一化位置，两者取值 0–1，X 向右、Y 向下。九宫格选择保持文字实际位置，Shift 同时设置 Pivot，Alt 同时归零偏移；不增加拉伸、固定矩形或四边距。Esc 仅恢复当前向量分量。

先在“设置 → 字幕样式”中保存预设，再右键目标轨道选择样式。轨道标题下的徽标显示已保存的样式名称。更换非空轨道的预设时，会询问是否修改已有 Clip：选“是”更新已有字幕及后续默认值；选“否”保留已有字幕，只更新后续默认值；选“取消”不修改。默认选“否”，没有全部轨道批量应用入口。可以关闭轨道自动应用；此时保留轨道预设，但新增字幕使用样式面板当前选中的预设。重新开启后，后续创建再使用轨道默认值。样式和字体资源在一次事务中提交，字幕时间与特效保持原值，可撤销。拆分和跨轨移动保留 Clip 自身样式；个人预设库后续修改或删除不会自动改写项目快照。

逐字高亮按完整 Unicode 字素分配时间。样式面板的“高亮样式”可选择个人字幕样式预设；点击“逐字高亮”将其填充、描边、宽度与阴影保存为单份视觉快照，保留整句原有字体、字号和字形几何。已有逐字片段时保留时间，只替换外观。“默认高亮”保留原有默认颜色行为；“清除高亮”同时清除片段和快照。仅切换下拉框、语言或主题不会提交项目事务。
6. 拆分前先在字幕文字中放置光标，并将播放位置移到该句内部。拆分继承轨道；合并相邻句要求同轨、时间、图层顺序与效果可兼容，不能静默丢弃不同效果。
7. Ctrl/Cmd+S 保存，Ctrl/Cmd+Shift+S 另存为，Ctrl/Cmd+O 打开项目。文本框之外 Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。

## 特效编辑

时间线选择字幕 Clip；特效页编辑对应属性，不再显示独立图层列表或第二块预览。展开轨道后，所有 Clip 的全部已有动画属性持续显示，在该轨道内、各自 Clip 上方绘制；按属性并集安排动画行，位置／缩放两个分量共用一行，可整体收起。属性名保持显示，数值仅悬停关键帧时显示；标签在曲线裁剪结束后绘制，保持在可见轨道范围内。选择属性后，在当前播放位置添加关键帧；不同位置可连续新增，同一位置更新原点。点击关键帧暂停并定位视频，在特效面板修改数值与插值方式；修改其他可动画属性时使用同一个关键帧时间。未选关键帧时，已有动画的属性编辑播放头对应关键帧，无动画的属性修改基础值。支持撤销和重做；实际键盘输入在切换目标前提交，非法输入保留并阻止切换。非法字段可按 Esc 恢复，播放与寻址仍可用。主动寻址或开始播放退出固定关键帧目标；存在非法草稿时保留其原始目标。时间线可拖动关键帧时间和值，时间限制在所属片段范围内。支持保持、线性、缓入、缓出和缓入缓出。

特效页不提供字幕名称草稿；字幕内容由字幕面板负责。开始、结束时间字段上方显示明确标签，错误和编辑目标仅在有内容时占用空间。

预设下拉框中的淡入淡出、淡入、淡出、弹入、弹出、滑入与滑出读取内置 [DSL 脚本](effect-dsl.md)，按目标 Clip 时长编译为可继续编辑的动画轨道。设置中的“特效脚本”页管理个人模板及导入导出，具备逐 Token 高亮、上下文补全、语法提示和行列诊断；个人库与项目、布局分开保存；设置只管理脚本，保存后从工作台“应用预设”应用。位置和缩放在数据及动画中各是一个 Vector，双分量草稿在统一事务内提交。X/Y 标记不横向错位，重叠时合成黄色白边标记，共同纵向拖动保留两分量差值。填充和描边各使用一个完整 RGBA 关键帧，RGB 与 Alpha 在同一动画行显示。

路径使用三次 Bézier，在唯一视频预览中编辑端点和控制柄。按钮及双击画布支持追加端点，删除末端保留最小路径；清除路径同时清除进度动画。图形、图片、分组和蒙版工具从工作台流程中移除，底层场景模型及已保存数据仍由渲染器验证。视频手势开始时暂停并冻结目标，完成后产生一次 Undo；取消捕获或切换选择取消未提交手势。

样式和特效面板均提供“恢复自动位置”，一个事务清除显式锚点位置、局部位移、位置动画、路径与路径进度，恢复当前样式自动对齐；其他特效保留，重复恢复不增加 Undo。自动水平对齐与位置测量共同使用实际字形边界，居中时水平偏移精确为 0，左／右对齐使用正／负边距；自动转显式保持文字位置。时间线竖条的粘滞／步进控制统一移动、裁剪和关键帧量化，Alt 临时绕过；显示分度随缩放细化至毫秒。

粘滞按钮使用磁铁图标。吸附实际成立时在精确目标时间绘制竖向框线；按 Alt、无效放置、夹紧后不再对齐、释放或取消会清除指示。能量图与波形使用独立工具按钮隐藏或显示，保留分析数据、视口和播放位置；当前会话停靠／浮动同一面板时保留开关。时间线的轨道、文字、Clip、曲线和标记随深浅主题调整；展开动画行使用轻薄底板，使曲线在能量图上保持可读。

裁剪保留原有动画相位并补齐裁剪边界关键帧；移动平移整层与关键帧的显示时间；拉伸同时缩放关键帧、路径和卡拉 OK 时间。片段之外不保存关键帧，结束关键帧可以位于片段结束边界。

## 保存、资源与设置

项目采用严格版本化 JSON，字幕时间保存有理数，保留原始精度。当前版本 **3** 保存字幕轨道、TrackId、Anchor / Pivot / Offset、完整位置／缩放向量和裁剪曲线区间；本轮明确不支持版本 1／2 项目。个人布局和快捷键使用独立迁移，不属于项目升级。保存通过临时文件原子替换；打开时检查版本、必需字段、引用、同轨碰撞、数值及预算，不接受未知或重复字段。

视频位于项目目录内时使用规范相对引用，位于项目目录外或路径无法跨平台表示时使用绝对外部引用，不复制视频。打开视频的相对输入以当前项目目录为基准；未保存项目使用会话临时目录。每次保存和另存为均按目标项目目录重新选择视频引用形式，旧项目内的绝对视频引用在普通保存时也会规范化，并继续指向原视频；整个项目目录连同视频一起搬移后，相对引用可直接恢复。字体导入项目资源目录，可记录 SHA-256。另存为迁移托管资源并重新核对哈希，托管相对路径不能越出项目目录。跨目录迁移会清空旧撤销历史，避免撤销恢复已失效的相对路径；同目录保存保留历史，不增加保存事务。重新打开项目要求媒体流、画布尺寸和时间原点与实际媒体一致；媒体起点未知时采用明确的零原点约定。

独立设置窗口包含外观与语言、快捷键、字幕样式、特效脚本、配色、媒体、工程、预览和时间后续处理器九页。[时间后续处理器](timing-post-processor.md)为全局样式预设保存关联的处理参数。外观页选择系统／浅色／深色主题、系统／简体中文／英文语言及菜单模式；主色集中在配色页。切换立即生效并保存。主窗口和设置使用共享间距、控件高度与字号，样式／特效／压制页签采用 13 px 图标标题。音量同样持久化，静音为当前会话状态。正常设置位于用户应用数据目录；独立测试可用 `AEGINEXT_PREFERENCES_DIRECTORY` 指定隔离目录。

配色页提供经典、冰蓝、暖焰、灰阶音频图方案，以及低／中／高能量和波形颜色输入。内置方案按实际主题解析为深色或浅色版本；经典在深色下逐色保留旧语谱算法，浅色使用明亮底色和深能量色。手动输入或选择自定义后关闭主题适配，保留用户颜色；自定义能量颜色在三个色标间插值。能量色和主色为不透明颜色，波形允许 Alpha。页面中预览当前主题的渐变与波形，有效输入立即更新停靠及浮动时间线；不重新分析媒体、不改变视窗，也不修改项目或 Undo。配色属于个人偏好，重启恢复，旧偏好缺少配色字段时继续使用经典方案。方案项身份稳定，语言更新只改显示文字，任何内置方案可直接切回经典；语言、主题切换保留未完成颜色草稿。

“恢复默认配色”同时恢复默认高亮色和经典音频图方案，清除这几个颜色字段的未完成或非法输入，并一次应用及保存。主题、语言、菜单模式、快捷键、音量和项目保持原值。

快捷键通过“录入”捕获实际组合键，手势框只读，禁止文字输入和粘贴；允许禁用单项、恢复默认。保存前分别检测手势格式和真实冲突，冲突提示指出占用命令，当前命令重复录入自身手势不算冲突；`CmdOrCtrl` 自动映射当前平台的主修饰键。录制从按下持续到全部按键释放，消费字符输入、重复按下及对应释放，避免录入过程触发业务；Esc 取消，窗口失焦或关闭清理录制状态。应用内各页和设置窗口统一路由，输入文本时保留空格、方向键、删除和文本撤销，F8／F9 仍可打轴。此处“全局”指应用内全局，切到其它应用后的系统热键尚未实现。窗口菜单和按钮提示跟随实际绑定更新。

macOS 默认使用系统菜单，可在外观设置切换成主窗口菜单；窗口菜单只显示在主工作台，浮窗、设置和辅助窗口仍使用共享命令上下文。每个已注册窗口独立拥有长期存在的原生菜单根，焦点切换不清空菜单。主题和快捷键变化原位更新菜单项；语言变化在安全的菜单生命周期中更新分组并保留根身份。系统菜单的跨窗口实现见 [窗口基础](workspace-windowing.md)。

顶部菜单项仅获得焦点但未展开时，不阻断全局快捷键；F8 打轴和空格播放仍可执行。展开菜单、下拉框、模态窗口和文本输入继续保留既有本地键盘行为。对应按键释放与重复仍由窗口注册表统一消费。

主窗口和样式预设共享可搜索字体下拉框；输入按名称筛选，箭头展开实际系统字体及项目／预设字体，选择、回车或失焦确认，Escape 恢复已确认字体。搜索过程不会逐字修改字幕或污染撤销记录。

字幕样式预设在设置中独立管理，支持新增、复制、修改、删除、从当前字幕捕获和套用；主窗口的样式页可直接选择并套用到当前字幕。预设文件为 `.aegistyles`，包含样式、Anchor / Pivot / Offset 位置及所需项目字体字节和 SHA-256，可跨项目导入；设置样式页可编辑模板位置。系统字体预设仍要求目标机器存在相应字体。导入整体验证，重名或重复标识会拒绝，不覆盖现有库。库与项目分别存储，字体套用时导入目标项目托管资源并支持撤销。

样式库最多 256 项，单字体 32 MiB、字体总量 64 MiB、预设文件 96 MiB；验证数值、哈希、字段和版本后原子提交。仅样式页在保存或导入期间暂时禁用，避免异步提交覆盖新的编辑草稿。

日志通过“视图 → 日志”打开，可停靠、浮动、隐藏和重新打开。标准布局中它是底部非活动标签，错误不会自动抢走当前面板；菜单未读数量提示尚未查看的错误。当前会话保留最近 2,000 条操作、警告和完整异常，支持等级／文本过滤、复制和清空；持续媒体错误按状态变化记录。完整异常直接在对应记录中展开为可选择文字，不使用底部独立详情输入框；复制仍包含完整错误。日志不跨重启保存。

## 播放与显示边界

预览通过独立 FFmpeg 解码与 SDL3 输出音频，常规队列预填充约 200 ms，上限 250 ms。时钟以已提交音频减去尚未消费的样本和一块设备缓冲估计推进，存在设备块量化，不等同硬件 DAC 时钟。无音轨或设备失败时仍可播放视频，并显示音频错误。

语谱分析独立读取 16 kHz 单声道 PCM，生成有界波形与对数频率谱，不占用播放队列。当前分析预算最多六小时；超出范围报告错误。预览默认上限 960×540，可选择 1280×720 或 1920×1080，字幕场景与视频最终派生为 SDR 图像；HDR 压制走独立原始帧链路，见 [导出说明](export.md)。

文本支持基本中日文／拉丁文、换行与纯单方向文本。混合双向段落和按 run 细粒度字体回退尚未完成，不把简单单方向塑形当作完整国际排版。

所有颜色字段共用连续输入栏：32×32 的颜色预览方块、文本输入、32×32 的模式按钮及取色按钮。模式按钮在 HEX `#RRGGBB`／`#RRGGBBAA` 与逗号分隔 RGBA `255,255,255,255` 之间切换；RGBA 四项均为 0–255 的 sRGB 整数。取色按钮打开既有颜色选择器的取色内容，颜色预览、文字和取色器双向联动。Enter／失焦提交有效草稿，Esc 恢复当前颜色；非法草稿保留并就地提示，修正或恢复后可切换模式。配色主色保留不透明度限制。仅切换表示方式不提交项目事务，未编辑 HDR 数值在回填、模式、语言与主题切换时保持原精度；DSL 的 `rgba(...)` 仍使用线性色。正文输入共享字体与居中行框，DSL 保留等宽顶部对齐，日志长文本保留顶部对齐。
