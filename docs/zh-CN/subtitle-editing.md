# 字幕详细编辑与格式交换

[English](../subtitle-editing.md) | [简体中文](subtitle-editing.md)

字幕列表始终显示正文。类型列由内容自动判断：存在逐字时间时为“高亮”，存在局部样式时为“富文本”，其余为“普通”。高亮和富文本共用内容模型，高亮字幕也可以包含不同字体、颜色和装饰。

## 打开、浮动与贴靠

选中字幕，点击列表工具栏中的“详细编辑”，或使用该行右键菜单中的同名操作。详情作为工作区子窗口打开；拖动面板标签可以贴靠回主窗口或再次浮动。重复打开会激活同一个面板，详情随当前主选中字幕变化。列表正文的双击仍用于选词。

布局记住详情面板的贴靠、浮动和隐藏位置。属性采用灰色标题在上、输入在下的完整字段组，成对的 X/Y 输入保持同行。窄窗按组换行，属性组可折叠以保留正文编辑空间；顶部与样式工具栏固定，正文和代码区可滚动。数值输入隐藏微调按钮，保留精确原值。关闭详情或切换布局前会检查草稿；无效输入需要修正，或用“重置”明确放弃。旧布局升级后详情初始隐藏，原有面板位置保持不变。

## 两个编辑切页

- **富文本**：直接编辑最终显示的文字，选择正文后使用字体、字号、粗斜体、下划线、删除线、颜色、描边或阴影工具。选择不会因为焦点进入工具栏而丢失。三个选区图标分别将预设应用到正文选区、应用编辑后的选区样式、清除选区局部样式，只影响选中正文。样式面板原有整行“应用样式”替换基础样式并清除局部覆盖，保留高亮时间。
- **AegiSub代码**：编辑受支持的 ASS 文本标签，代码选区与可读文字选区映射。此页只编辑字幕内容与样式；位置仍由项目原生位置编辑器和特效管理，手动 `\pos` 标签会显示诊断并要求移除。无效标签或数值保持为代码草稿，预览保留最后有效内容；修正或恢复后才能切行、切页、关闭详情和保存。原始正文若包含无法无损表示为 ASS 的字面转义，此页显示兼容性原因，正文仍可正常编辑和保存项目。

打开“启用高亮”后，逐字时间轴显示在富文本正文下方，按完整字素分配当前句时间。每个汉字、完整 emoji 或组合字符分别作为一个片段；导入的多字片段会保留原时长并按字素拆分。关闭开关清除逐字时间，保留高亮配置用于再次启用。

选中片段后打开弹出编辑器，其中包含吸附、片段时长、句前留白和高亮方式。也可通过片段右端拖拽改变长度；后续片段顺延，字幕整句起止时间不变。“吸附”默认开启，拖拽会对齐 10 毫秒网格、开始拖拽时的原片段边界及字幕结束线；开关不修改项目，按住 Alt 可临时关闭。句前留白产生整句开始前的等待，句尾剩余时间形成留白。时间轴仍显示已有等待空隙，旧裁剪内容的时间原点保留。

顶部“高亮样式”开关将共享样式区切换为正文选区样式或高亮样式。高亮模式只编辑颜色、描边和阴影；字体、字号、文字装饰和排版由正文负责，对应控件禁用，三个正文选区操作也不可用。共用预设选择器切换为高亮预设，选中即套用。高亮参数使用共享样式区，不再显示独立高亮参数区或“应用高亮”按钮。样式面板继续用于正文样式。

高亮字段在按 `Enter` 或失焦时提交；非法原始输入保留为可编辑草稿，`Esc` 恢复该字段。片段时长可超出当前字幕区间并提交，不自动拉长整句。时间轴右侧红框显示溢出部分，便于继续编辑；长度必须为正，句前留白不得小于 0。正文和代码页的 `Esc` 恢复当前未提交内容。“重置”放弃详情未提交的内容、样式和时间草稿。

切页只切换视图，不清除样式或逐字时间。连续正文输入在提交边界合并为一次撤销；一次正文样式应用、高亮预设选择、合法高亮字段提交、启用切换和拖拽分别形成一次撤销。文字增删只重新分配受影响片段，其他片段的身份和时间保留。完整 emoji 和组合字符不会被光标、选区或输入法拆开。

## 段内播放

详情顶部只有一个播放／暂停按钮及“循环”开关。循环默认关闭，点击播放后试听当前选中片段；没有选中片段时播放整句，播放中点击同一按钮暂停。播放期间可以切换循环，暂停时切换不会自动发声。焦点从正文移到详情工具栏不暂停，离开整个详情或使浮动子窗口失去激活后立即暂停；再次聚焦不会自动发声。切行、删除目标、关闭详情、项目或媒体重置以及主窗口主动定位会取消旧循环。音视频共用同一有范围的播放链路。

## ASS 与 SRT

格式菜单包含：

- **格式 → Aegisub → 导入／导出**：原生 `.ass`。
- **格式 → SRT → 导入／导出**：`.srt` 正文与时间。

文件菜单中的视频导出保持原位置。已有字幕导入、导出快捷键继续对应 SRT；ASS 命令默认没有快捷键，可以在设置中配置。

每次导入生成独立轨道。合法重叠字幕保留原始时间并分配到额外轨道，整批导入可一次撤销。ASS 依据源 `PlayRes` 映射到当前画布，不改变项目分辨率；缺失分辨率会提示，非法分辨率、时间、编码、结构或资源上限会拒绝整批导入。

ASS 交换支持基础与局部样式、样式重置、颜色和透明度、描边与阴影、对齐和静态位置，以及 `\k`、`\kf`／`\K`、`\ko`。未支持的标签和动画列出具体损失及受影响字幕，确认继续才转换；`\move` 不转换为项目特效，项目移动行为由特效系统实现。

导出包含全部字幕轨道。SRT 稳定按时间排序，重叠内容保持独立条目；富文本、逐字时间和项目特效的损失需要确认。ASS 使用实际图层顺序生成层级。项目保持精确时间，SRT 只在文件边界量化到毫秒，ASS 量化到百分之一秒；逐字时间按累计边界量化，无法保持正时长时拒绝导出。文件使用严格 UTF-8，兼容读取 BOM，成功生成后通过同目录临时文件原子替换目标。
